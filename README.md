## Project Overview
The AI-Powered Campus Lost & Found System is a centralized web platform designed for NUBT Khulna students, faculty, and staff to streamline the reporting, searching, and recovery of misplaced belongings across campus using multimodal AI analysis.

## Objectives
- Provide a secure, centralized digital repository for all campus lost and found items.
- Automate image feature extraction and tagging using Gemini Vision API.
- Perform automated semantic similarity matching between lost reports and found items.
- Prevent false claims through AI-guided verification prompts.

## Core Features
- **User Authentication:** Secure registration and login using JWT and bcrypt.
- **Item Reporting:** Forms to report lost items and upload found item photos.
- **AI Vision Tagging:** Automatic extraction of category, color, brand, and details via Gemini AI.
- **Smart Matching Engine:** Calculates similarity confidence scores for fast recovery.
- **Claim Verification Portal:** Anti-fraud protection using dynamic security questions.
