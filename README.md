# AI-Powered Campus Lost & Found System

**Team ID:** CSE4104-7F-T07 | **Section:** 7F | **Course:** CSE 4104 (NUBTK)

## Project Overview
A web-based campus lost-and-found platform that enables students, faculty, and security/admin staff to report lost or found items, run AI-assisted visual tagging and similarity matching, and verify ownership claims securely.

- **AI Service:** Google Gemini API (Multimodal Vision)
